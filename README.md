# Aliceararebooks

Static website for Aliceararebooks, an antique & rare books resale business.

- `index.html` — the whole site (HTML, CSS, JS inline)
- `assets/logo.jpg` — logo

**Set your shop links:** edit the `SHOP_LINKS` object near the bottom of `index.html`.

**Host it free:** enable GitHub Pages (Settings → Pages → Deploy from branch → `master` / root).
